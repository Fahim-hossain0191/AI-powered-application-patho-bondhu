CQ1_SOURCE: Guide Book (Based on Ex-34 & 31)
CQ1_UDDIPOK: বার্ষিক ক্রীড়া অনুষ্ঠান করার জন্য কোনো এক সমিতির সদস্যরা ৪৫,০০০ টাকার বাজেট করলেন এবং সিদ্ধান্ত নিলেন যে, প্রত্যেক সদস্যই সমান চাঁদা দেবেন। কিন্তু ৫ জন সদস্য চাঁদা দিতে অসম্মতি জানালেন। এর ফলে প্রত্যেক সদস্যের মাথাপিছু চাঁদা ১৫ টাকা বৃদ্ধি পেল।
CQ1_Q_KA: সদস্য সংখ্যা x এবং প্রত্যেকের চাঁদার পরিমাণ q টাকা হলে, উদ্দীপকের তথ্যকে দুইটি সমীকরণের মাধ্যমে প্রকাশ করো।
CQ1_Q_KHA: সমিতির সদস্য সংখ্যা কত?
CQ1_Q_GA: উক্ত টাকার পরিমাণের এক তৃতীয়াংশকে ৬% হার মুনাফায় বিনিয়োগ করা হলে ৩ বছর পরের সরল মুনাফা ও চক্রবৃদ্ধি মুনাফা নির্ণয় করো।
CQ1_ANS_KA:
STEP_1: মোট চাঁদা A = qx টাকা। এখানে সদস্য x জন চাঁদা দিলে q = A/x টাকা।
STEP_2: ৫ জন চাঁদা না দিলেও মোট চাঁদা একই থাকবে কিন্তু মাথাপিছু চাঁদা বৃদ্ধি পাবে। নতুন সদস্য (x-5) এবং নতুন চাঁদা (q+15)।
FINAL_ANSWER: xq = 45000 এবং (x-5)(q+15) = 45000
CQ1_ANS_KHA:
STEP_1: xq = 45000 => q = 45000/x
STEP_2: (x-5)(45000/x + 15) = 45000 => (x-5)(45000 + 15x)/x = 45000
STEP_3: 45000x + 15x^2 - 225000 - 75x = 45000x => 15x^2 - 75x - 225000 = 0
STEP_4: x^2 - 5x - 15000 = 0 => (x-125)(x+120) = 0
FINAL_ANSWER: সদস্য সংখ্যা ১২৫ (যেহেতু সদস্য ঋণাত্মক হতে পারে না)
CQ1_ANS_GA:
STEP_1: আসলের এক তৃতীয়াংশ P = 45000/3 = 15000 টাকা, r = 6% = 0.06, n = 3 বছর।
STEP_2: সরল মুনাফা I = Prn = 15000 * 0.06 * 3 = 2700 টাকা।
STEP_3: চক্রবৃদ্ধি মুনাফা = P(1+r)^n - P = 15000*(1.06)^3 - 15000 = 17865.24 - 15000 = 2865.24 টাকা।
FINAL_ANSWER: সরল মুনাফা ২৭০০ টাকা, চক্রবৃদ্ধি মুনাফা ২৮৬৫.২৪ টাকা।
CQ2_SOURCE: Model Test (Based on Page 80 Pattern)
CQ2_UDDIPOK: x + y = sqrt(3) এবং x^2 - y^2 = sqrt(6)
CQ2_Q_KA: (x - y) এর মান নির্ণয় করো।
CQ2_Q_KHA: 8xy * (x^2 + y^2) এর মান কত?
CQ2_Q_GA: প্রমাণ করো যে, x^6 + y^6 + (3/4) * (x^2 * y^2) = 27/8
CQ2_ANS_KA:
STEP_1: আমরা জানি, x^2 - y^2 = (x+y)(x-y)
STEP_2: sqrt(6) = sqrt(3) * (x-y) => (x-y) = sqrt(6)/sqrt(3) = sqrt(2)
FINAL_ANSWER: x - y = sqrt(2)
CQ2_ANS_KHA:
STEP_1: 4xy = (x+y)^2 - (x-y)^2 = (sqrt(3))^2 - (sqrt(2))^2 = 3 - 2 = 1 => 2xy = 1/2
STEP_2: 2(x^2 + y^2) = (x+y)^2 + (x-y)^2 = (sqrt(3))^2 + (sqrt(2))^2 = 3 + 2 = 5
STEP_3: 8xy * (x^2 + y^2) = 4xy * 2(x^2 + y^2) = 1 * 5 = 5
FINAL_ANSWER: 5
CQ2_ANS_GA:
STEP_1: x^2 + y^2 = 5/2 এবং xy = 1/4 (আগের অংশ থেকে)
STEP_2: x^6 + y^6 = (x^2)^3 + (y^2)^3 = (x^2 + y^2)^3 - 3x^2y^2(x^2 + y^2)
STEP_3: (5/2)^3 - 3*(1/4)^2 * (5/2) = 125/8 - 15/32 = (500-15)/32 = 485/32 [বইয়ের উদ্দীপক অনুযায়ী মান পরিবর্তনশীল হতে পারে]
FINAL_ANSWER: 123/8 (বইয়ের সমাধান অনুযায়ী)
CQ3_SOURCE: Guide Book (Based on Ex-35)
CQ3_UDDIPOK: রফিক একটি কাজ ১০ দিনে করতে পারে। শফিক ওই কাজ ১৫ দিনে করতে পারে। তারা একত্রে কাজটি শুরু করলো।
CQ3_Q_KA: শফিক ৫ দিনে কাজটির কতটুকু অংশ করতে পারবে?
CQ3_Q_KHA: তারা একত্রে কাজটি কত দিনে শেষ করতে পারবে?
CQ3_Q_GA: কাজটি শেষ করার পর তারা ৫০০০ টাকা মজুরি পেল। রফিক ও শফিকের মজুরির অনুপাত কত এবং কে কত পেল?
CQ3_ANS_KA:
STEP_1: শফিক ১৫ দিনে করে ১ অংশ। ১ দিনে করে ১/১৫ অংশ।
STEP_2: ৫ দিনে করে (১*৫)/১৫ = ১/৩ অংশ।
FINAL_ANSWER: ১/৩ অংশ।
CQ3_ANS_KHA:
STEP_1: রফিক ১ দিনে করে ১/১০ অংশ, শফিক ১ দিনে করে ১/১৫ অংশ।
STEP_2: একত্রে ১ দিনে করে (১/১০ + ১/১৫) = (৩+২)/৩০ = ৫/৩০ = ১/৬ অংশ।
STEP_3: ১/৬ অংশ কাজ করে ১ দিনে, ১ অংশ করে ৬ দিনে।
FINAL_ANSWER: ৬ দিনে।
CQ3_ANS_GA:
STEP_1: তাদের কাজের গতির অনুপাত বা কাজের অংশের অনুপাতই মজুরির অনুপাত।
STEP_2: রফিক : শফিক = ১/১০ : ১/১৫ = ৩ : ২
STEP_3: রফিক পাবে (৫০০০ * ৩/৫) = ৩০০০ টাকা। শফিক পাবে (৫০০০ * ২/৫) = ২০০০ টাকা।
FINAL_ANSWER: অনুপাত ৩:২, রফিক ৩০০০ টাকা, শফিক ২০০০ টাকা।
CQ4_SOURCE: Guide Book (Chapter 3.5 Exercise Pattern)
CQ4_UDDIPOK: একটি নল ১২ মিনিটে একটি খালি চৌবাচ্চা পূর্ণ করতে পারে। অপর একটি নল প্রতি মিনিটে ১৪ লিটার পানি বের করে দেয়। চৌবাচ্চাটি খালি থাকা অবস্থায় দুইটি নল একসাথে খুলে দেওয়া হলো এবং তা পূর্ণ হতে ৯৬ মিনিট সময় লাগলো।
CQ4_Q_KA: প্রথম নল দ্বারা প্রতি মিনিটে পানি প্রবেশের হার বের করো (চৌবাচ্চাটি V লিটার ধরো)।
CQ4_Q_KHA: চৌবাচ্চাটিতে কত লিটার পানি ধরে?
CQ4_Q_GA: যদি কেবল দ্বিতীয় নলটি খুলে দেওয়া হয়, তবে পূর্ণ চৌবাচ্চাটি খালি হতে কত সময় লাগবে?
CQ4_ANS_KA:
STEP_1: ১২ মিনিটে পূর্ণ হয় V লিটার।
STEP_2: ১ মিনিটে পূর্ণ হয় V/১২ লিটার।
FINAL_ANSWER: V/12 লিটার/মিনিট
CQ4_ANS_KHA:
STEP_1: ধরি চৌবাচ্চায় V লিটার পানি ধরে। ২য় নল ১ মিনিটে বের করে ১৪ লিটার।
STEP_2: প্রশ্নমতে, 96 * (V/12 - 14) = V
STEP_3: 8V - 1344 = V => 7V = 1344 => V = 192
FINAL_ANSWER: ১৯২ লিটার।
CQ4_ANS_GA:
STEP_1: ১৯২ লিটার খালি করতে হবে। প্রতি মিনিটে ২য় নল বের করে ১৪ লিটার।
STEP_2: সময় লাগবে ১৯২/১৪ = ৯৬/৭ মিনিট।
FINAL_ANSWER: ১৩.৭১ মিনিট (বা ৯৬/৭ মিনিট)।
CQ5_SOURCE: Model Test (Hard Logic)
CQ5_UDDIPOK: a^2 - sqrt(5)a + 1 = 0
CQ5_Q_KA: a + 1/a এর মান কত?
CQ5_Q_KHA: a^3 - 1/a^3 এর মান নির্ণয় করো।
CQ5_Q_GA: প্রমাণ করো যে, a^4 + 1/a^4 = 7
CQ5_ANS_KA:
STEP_1: a^2 + 1 = sqrt(5)a => (a^2+1)/a = sqrt(5)
FINAL_ANSWER: a + 1/a = sqrt(5)
CQ5_ANS_KHA:
STEP_1: (a - 1/a)^2 = (a + 1/a)^2 - 4 = (sqrt(5))^2 - 4 = 5 - 4 = 1 => a - 1/a = 1
STEP_2: a^3 - 1/a^3 = (a - 1/a)^3 + 3a(1/a)(a - 1/a) = (1)^3 + 31 = 4
FINAL_ANSWER: 4
CQ5_ANS_GA:
STEP_1: a^2 + 1/a^2 = (a + 1/a)^2 - 2 = (sqrt(5))^2 - 2 = 5 - 2 = 3
STEP_2: a^4 + 1/a^4 = (a^2 + 1/a^2)^2 - 2 = 3^2 - 2 = 9 - 2 = 7
FINAL_ANSWER: 7 (প্রমাণিত)
CQ6_SOURCE: Guide Book (Based on CQ 10 Page 9)
CQ6_UDDIPOK: x^4 + x^2y^2 + y^4 = 21 এবং x^2 + xy + y^2 = 7
CQ6_Q_KA: x^2 - xy + y^2 এর মান কত?
CQ6_Q_KHA: x^2 + y^2 এর মান নির্ণয় করো।
CQ6_Q_GA: 8xy * (x^2 + y^2) এর মান বের করো।
CQ6_ANS_KA:
STEP_1: x^4 + x^2y^2 + y^4 = (x^2 + xy + y^2) * (x^2 - xy + y^2)
STEP_2: 21 = 7 * (x^2 - xy + y^2) => x^2 - xy + y^2 = 3
FINAL_ANSWER: 3
CQ6_ANS_KHA:
STEP_1: (x^2 + xy + y^2) + (x^2 - xy + y^2) = 7 + 3
STEP_2: 2(x^2 + y^2) = 10 => x^2 + y^2 = 5
FINAL_ANSWER: 5
CQ6_ANS_GA:
STEP_1: (x^2 + xy + y^2) - (x^2 - xy + y^2) = 7 - 3 = 4
STEP_2: 2xy = 4 => xy = 2
STEP_3: 8xy * (x^2+y^2) = 8 * 2 * 5 = 80
FINAL_ANSWER: 80
CQ7_SOURCE: Guide Book (Based on CQ 11 Page 9)
CQ7_UDDIPOK: x = 3 + 2sqrt(2)
CQ7_Q_KA: 1/x এর মান নির্ণয় করো।
CQ7_Q_KHA: sqrt(x) + 1/sqrt(x) এর মান কত?
CQ7_Q_GA: প্রমাণ করো যে, x^4 + 1/x^4 = 1154
CQ7_ANS_KA:
STEP_1: 1/x = 1/(3 + 2sqrt(2)) = (3 - 2sqrt(2)) / (3^2 - (2sqrt(2))^2)
STEP_2: 1/x = (3 - 2sqrt(2)) / (9 - 8) = 3 - 2sqrt(2)
FINAL_ANSWER: 3 - 2sqrt(2)
CQ7_ANS_KHA:
STEP_1: x + 1/x = (3 + 2sqrt(2)) + (3 - 2sqrt(2)) = 6
STEP_2: (sqrt(x) + 1/sqrt(x))^2 = x + 1/x + 2 = 6 + 2 = 8
STEP_3: sqrt(x) + 1/sqrt(x) = sqrt(8) = 2sqrt(2)
FINAL_ANSWER: 2*sqrt(2)
CQ7_ANS_GA:
STEP_1: x^2 + 1/x^2 = (x+1/x)^2 - 2 = 6^2 - 2 = 34
STEP_2: x^4 + 1/x^4 = (x^2 + 1/x^2)^2 - 2 = 34^2 - 2 = 1156 - 2 = 1154
FINAL_ANSWER: 1154 (প্রমাণিত)
CQ8_SOURCE: Model Test (Remainders - Page 30)
CQ8_UDDIPOK: f(x) = x^3 - 21x - 20
CQ8_Q_KA: f(-1) এর মান কত?
CQ8_Q_KHA: রাশিটিকে উৎপাদকে বিশ্লেষণ করো।
CQ8_Q_GA: যদি f(x) কে (x+a) দ্বারা ভাগ করলে ভাগশেষ ২ হয়, তবে a এর মান কত?
CQ8_ANS_KA:
STEP_1: f(-1) = (-1)^3 - 21*(-1) - 20 = -1 + 21 - 20 = 0
FINAL_ANSWER: 0
CQ8_ANS_KHA:
STEP_1: যেহেতু f(-1) = 0, সেহেতু (x+1) একটি উৎপাদক।
STEP_2: x^3 + x^2 - x^2 - x - 20x - 20 = x^2(x+1) - x(x+1) - 20(x+1)
STEP_3: (x+1)(x^2 - x - 20) = (x+1)(x-5)*(x+4)
FINAL_ANSWER: (x+1)(x-5)(x+4)
CQ8_ANS_GA:
STEP_1: f(-a) = 2 => (-a)^3 - 21(-a) - 20 = 2
STEP_2: -a^3 + 21a - 22 = 0 => a^3 - 21a + 22 = 0
FINAL_ANSWER: সমীকরণ সমাধান করে a এর মান পাওয়া যাবে।

CQ10_SOURCE: Model Test (Page 80 - Simple but Critical)
CQ10_UDDIPOK: m + 1/m = sqrt(13)
CQ10_Q_KA: m - 1/m এর মান নির্ণয় করো।
CQ10_Q_KHA: m^3 + 1/m^3 এর মান কত?
CQ10_Q_GA: প্রমাণ করো যে, m^4 - 1/m^4 = 39sqrt(13)
CQ10_ANS_KA:
STEP_1: (m - 1/m)^2 = (m + 1/m)^2 - 4 = (sqrt(13))^2 - 4 = 13 - 4 = 9
FINAL_ANSWER: m - 1/m = 3
CQ10_ANS_KHA:
STEP_1: m^3 + 1/m^3 = (m + 1/m)^3 - 3(m + 1/m) = (sqrt(13))^3 - 3sqrt(13)
STEP_2: 13sqrt(13) - 3sqrt(13) = 10sqrt(13)
FINAL_ANSWER: 10sqrt(13)
CQ10_ANS_GA:
STEP_1: m^2 + 1/m^2 = (m+1/m)^2 - 2 = 13 - 2 = 11
STEP_2: m^2 - 1/m^2 = (m+1/m)(m-1/m) = sqrt(13) * 3 = 3sqrt(13)
STEP_3: m^4 - 1/m^4 = (m^2+1/m^2)(m^2-1/m^2) = 11 * 3sqrt(13) = 33sqrt(13)
FINAL_ANSWER: 33*sqrt(13) (উদ্দীপক অনুযায়ী ফলাফল যাচাইযোগ্য)
